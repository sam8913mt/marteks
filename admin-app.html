مدیریت دانلودها

لینک دانلود هر پلتفرم را اینجا عوض کنید، پلتفرم تازه اضافه کنید یا فایل را مستقیم در مخزن GitHub سایت بارگذاری کنید. بعد از «ذخیره»، بخش دانلود سایت خودکار به‌روز می‌شود.

۱. اتصال به GitHub

توکن را از کجا بسازم؟
  1. در GitHub بروید به Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens.
  2. روی Generate new token بزنید و برای انقضا یک زمان کوتاه (مثلاً ۳۰ روز) بگذارید.
  3. در Repository access فقط همین مخزن را انتخاب کنید.
  4. در Permissions ← Repository permissions، گزینهٔ Contents را روی Read and write بگذارید.
  5. توکن را کپی کنید و همین‌جا بچسبانید.

توکن فقط در حافظهٔ همین صفحه می‌ماند، هیچ‌جا ذخیره نمی‌شود و فقط به api.github.com فرستاده می‌شود. توکن را برای کسی نفرستید.

۲. فهرست دانلودها

هر بخش یک کارت در سایت است. فایل APK یا EXE (و MSI، ZIP و …) را مستقیم از همین‌جا بارگذاری کنید؛ حداکثر ۷۰ مگابایت برای هر فایل. اگر فایل بزرگ‌تر است، آدرس مستقیم (https) بدهید. آدرس خالی = کارت «به‌زودی».
